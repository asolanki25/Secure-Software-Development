## Files

- `PassByValueDemo.java` — Question 2. Demonstrates how Java passes arguments: a primitive by value, a mutable object whose field is changed through a shared reference, and a reference reassignment that does not affect the caller (proving Java is pass-by-value).
- `output.txt` — real program output (Java 21).

## Run

```
javac PassByValueDemo.java
java PassByValueDemo
```

Requires Java 8 or later.
